# Public Value Recovery Research

A reproducible portfolio research project exploring how communities prioritise post-crisis recovery in the built environment.

## Research question

Which built-environment priorities do communities value most during post-crisis recovery, and how do these priorities differ between stakeholder groups?

## Project scope

This repository demonstrates a structured research workflow, including:

- Research planning and problem definition
- Data cleaning and validation
- Exploratory analysis of community priorities
- Visualisation of findings
- Plain-language communication for public audiences
- Documentation of methods, assumptions and limitations

## Methods

The project uses anonymised or simulated survey responses describing recovery priorities across housing, infrastructure, safety, community facilities and environmental resilience. Responses are cleaned, categorised and analysed using Python.

## Technologies

- Python
- pandas
- matplotlib
- Jupyter Notebook

## Data ethics

No confidential, identifiable, unpublished or institution-owned research data is included. Any data added to this repository must be openly licensed, fully anonymised, or clearly labelled as simulated.
