# Research Summary

## Purpose

This project examines how communities and stakeholders prioritise recovery needs after a crisis affecting the built environment.

## Approach

The analysis uses a structured dataset of anonymised or simulated responses. Responses are grouped by recovery category and stakeholder group, then summarised using descriptive statistics and visualisations.

## Intended outputs

- A ranked view of recovery priorities
- A comparison of priorities across stakeholder groups
- An accessible summary suitable for non-technical audiences

## Limitations

If simulated data is used, findings are illustrative rather than representative. Real-world research would require ethical approval, informed consent, anonymisation checks and appropriate data governance.

## Future extensions

- Add geospatial analysis using survey or aerial data
- Include qualitative theme analysis from open-text responses
- Build an interactive dashboard for public engagement
