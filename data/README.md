# Data

Place anonymised or simulated datasets in this folder.

Recommended file name:

```text
recovery_priorities.csv
```

Expected columns:

| Column | Description |
|---|---|
| `response_id` | Anonymous response identifier |
| `stakeholder_group` | Community member, local authority, business, NGO, etc. |
| `priority_category` | Housing, infrastructure, safety, community facilities, environment |
| `priority_score` | Numeric score from 1 to 5 |
| `comments` | Optional anonymised qualitative response |

Do not upload personal data, confidential research data, or data belonging to an employer or university.
